# Instance Repeater

LOTRO Lua plugin project for quick repeat instance runs: save a fellowship/raid roster, prepare sequential invitations and keep the UI compact.

## Collaboration

Claude and ChatGPT/Codex use the same repository as shared memory. Read `AGENTS.md` and `docs/handoff.md` before editing. Work sequentially on `main`, test, update the handoff, commit and push.

## Status

Repository collaboration scaffold initialized. Plugin source and automated tests still need to be imported and verified.

## Planned features

- 6-player and 12-player roster support
- Persistent saved players
- One sequential invitation Quickslot (subject to LOTRO restrictions)
- Expandable player list
- Leave Instance guidance or verified supported action
